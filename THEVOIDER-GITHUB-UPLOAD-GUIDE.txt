  ขั้น 6: ในหน้า repo กด "Add file" -> "Upload files"

แบบที่ 2 — ถ้าจะเอาไฟล์นักพัฒนาทั้ง 112 ไฟล์ขึ้นด้วย (ไม่จำเป็นต่อการใช้งาน)
----------------------------------------------------------------
เลือก 1 วิธีใน 3 วิธีนี้:

  วิธี ก: GitHub Desktop (ง่ายสุด ไม่มีลิมิตจำนวนไฟล์)
    1) โหลด GitHub Desktop ที่ desktop.github.com แล้วล็อกอิน
    2) File -> Add local repository -> เลือกโฟลเดอร์ thevoider ที่แตก ZIP แล้ว
       (ถ้าบอกว่าไม่ใช่ repo: เลือก "create a repository here" ชื่อ thevoider)
    3) มันจะเห็นไฟล์ทั้งหมด 112 ไฟล์ -> ใส่ข้อความ commit -> กด "Publish repository"
    4) ตั้ง Public ตามที่ถาม -> เสร็จ ไฟล์ขึ้นครบทุกไฟล์

  วิธี ข: คำสั่ง git (ถ้าเครื่องมี git ติดตั้งอยู่แล้ว)
    cd โฟลเดอร์ที่แตกZIP/thevoider
    git init
    git add .
    git commit -m "The Voider v0.7.0"
    git branch -M main
    git remote add origin https://github.com/auto578wqd/thevoider.git
    git push -u origin main

  วิธี ค: อัปโหลด ZIP ทั้งไฟล์ไปที่ Releases (สำหรับแจกจ่ายเป็นไฟล์เดียว)
    1) ในหน้า repo กด "Releases" -> "Create a new release"
    2) ตั้ง tag เช่น v0.7.0 -> ลากไฟล์ thevoider-v0.7.0-cr-pc-only.zip ลงช่องแนบไฟล์
       (Releases รับไฟล์ใหญ่ได้ถึง 2GB และไม่นับเป็นจำนวนไฟล์ใน repo)
    3) กด Publish release

  * หมายเหตุ: จะอัปโหลดผ่านหน้าเว็บแบบ "แบ่งชุดละ 100 ไฟล์" ก็ได้ แต่เสียเวลา
    และต้องเผื่อใจว่าลากวางครั้งละไม่เกิน 100 ไฟล์ — แนะนำวิธี ก มากกว่า

แก้ปัญหาเมื่อโหลดไม่ได้ (เรียงตามที่พบบ่อย)
----------------------------------------------------------------
1) คอนโซลขึ้น "ดึง manifest ไม่ได้จากทุก URL" + ลิสต์ URL เป็น 404:
   - ชื่อ repo ไม่ใช่ thevoider เป๊ะ ๆ (เช่นไปตั้งว่า TheVoider หรือ the-voider)
     -> ตัวพิมพ์เล็ก/ใหญ่สำคัญ ต้องเป็น thevoider ทั้งหมด
   - repo เป็น Private -> ต้องเปลี่ยนเป็น Public (Settings -> Danger Zone -> Change visibility)
   - ยังไม่มี branch main -> ต้องมีไฟล์อย่างน้อย 1 ไฟล์บน main (README ช่วยเรื่องนี้)
2) คอนโซลขึ้นเกี่ยวกับ SHA-256 ไม่ตรง:
   - ไฟล์ the-voider.lua โดนแก้/อัปโหลดไม่ครบ -> อัปโหลดใหม่จากแพ็กนี้เท่านั้น
     (SHA-256 ที่ถูกต้อง: b9d91ae217035fb1f87845058319187675d437906e17c0b9ba16c4d6ca27ad69)
3) โหลดได้วันนี้ แต่พรุ่งนี้เปลี่ยนไฟล์แล้วเกมยังโหลดของเก่า:
   - CDN (jsdelivr/raw.githack) เก็บแคชไว้ราว 12 ชม. -> ไป purge ที่
     https://www.jsdelivr.com/tools/purge ใส่ URL ของไฟล์ที่เปลี่ยน แล้วรันใหม่
4) ตรวจว่าไฟล์ขึ้นจริงหรือยัง เปิดลิงก์นี้ในเบราว์เซอร์ (ต้องเห็นโค้ด ไม่ใช่ 404):
