สถานการณ์ตอนนี้:
- คุณอัปโหลดไฟล์ทั้ง 4 ไฟล์ไปที่ repo "loader" (auto578wqd/loader) แล้ว
- และตั้ง Public เรียบร้อยแล้ว ✓ (ขั้นตอนนี้ทำถูกแล้ว ชอบมาก!)
- แต่ loader.lua ที่อัปไป ยังชี้ URL ไปที่ repo ชื่อ "thevoider" ซึ่งไม่มีอยู่
  -> ผมแก้ loader.lua ในแพ็กนี้ให้ชี้มาที่ repo "loader" แล้ว (แก้ 5 บรรทัด)

----------------------------------------------------------------
สิ่งที่ต้องทำ: แค่แทนที่ไฟล์ loader.lua ตัวเดียว (1 นาที)
----------------------------------------------------------------
1) โหลดแพ็กนี้ แตกไฟล์ (Extract All)
2) เปิด github.com/auto578wqd/loader
3) กด "Add file" -> "Upload files"
4) ลากไฟล์  loader.lua  (ตัวใหม่จากแพ็กนี้) เข้าไป
   * GitHub จะขึ้นว่าไฟล์นี้ "replace" ตัวเก่า — ถูกต้อง ปล่อยผ่าน
5) กด "Commit changes"
   * manifest.json กับ the-voider.lua ที่อัปไปแล้ว ใช้ได้อยู่แล้ว
     ไม่ต้องลบ ไม่ต้องอัปใหม่ ไม่ต้องแตะอะไรทั้งสองไฟล์

ปัญหาที่อาจเจอ
----------------------------------------------------------------

   - ยังไม่ได้แทนที่ loader.lua ตัวใหม่ (repo ยังมีตัวเก่าอยู่)
   - หรือ repo กลับไปเป็น Private อีก -> ต้องเป็น Public เสมอ
2) ขึ้นเกี่ยวกับ SHA-256 ไม่ตรง:
   - ไฟล์ the-voider.lua ใน repo ไม่ตรงต้นฉบับ -> อัปโหลดใหม่จากแพ็กนี้
     (the-voider.lua ที่ถูกต้อง: b9d91ae217035fb1f87845058319187675d437906e17c0b9ba16c4d6ca27ad69)
3) วันหลังแก้ไฟล์แล้วเกมยังโหลดของเก่า:
   - CDN แคชราว 12 ชม. -> purge ที่ https://www.jsdelivr.com/tools/purge
   - หรือเปลี่ยน URL ใน loadstring เป็น raw.githubusercontent.com โดยตรง

อัปเดตฉบับที่ 2 (2026-10-01): แก้บั๊ก Volt แล้ว — VoltCompat v1
================================================================
อาการเดิมที่คุณเจอ (จากคอนโซล Volt):
  :1: attempt to call a nil value
      -> ตอนนั้น repo ยังไม่มี loader.lua (โหลดได้หน้าเปล่า) หรือโหลดไฟล์เก่า
  :2434: attempt to index nil with 'Run' - function preflight / boot
      -> loader.lua โหลดถึง Volt แล้ว แต่โค้ดเดิมเขียนแบบ Lua บนคอม
         (ค้นหาโมดูลผ่าน rawget(_G,...)) ซึ่งแซนด์บ็อกซ์ของ Volt มองไม่เห็น
         -> ทุกโมดูลฝังกลายเป็น nil แล้วพังที่ preflight ทันที

สิ่งที่แก้แล้ว (VoltCompat v1 — แก้ใน loader.lua เท่านั้น):
  F1  _pkg x3 จุด: อ่านโมดูลจาก chunk env ก่อน แล้วค่อย fallback ไป _G
  F2  defaultLoadFn: หา loadstring/load แบบเดียวกัน
  F3  ค่า default ของ self.env: ใช้ getfenv() (chunk env) ก่อน _G
      เพื่อให้เจอ http_request ของ Volt เสมอ
  F4  การตรวจ bit32/bit: รู้จัก bit32 มาตรฐานของ Luau บน Volt
  * ทดสอบ syntax ด้วย AST parser แล้ว: ผ่าน
  * the-voider.lua กับ manifest.json ไม่ได้แตะเลย — SHA-256 ยังตรง 100%

สิ่งที่ต้องทำ: "แทนที่ loader.lua ตัวใหม่อีกครั้ง" (วิธีเดิมเป๊ะ)
  1) แตก zip นี้  2) Add file -> Upload files  3) ลาก loader.lua (ตัวใหม่)
  4) Commit changes   5) รัน loadstring เดิม
