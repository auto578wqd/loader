1) โหลดแพ็กนี้ แตกไฟล์ (Extract All)
2) เปิด github.com/auto578wqd/loader
3) กด "Add file" -> "Upload files"
4) ลากไฟล์  loader.lua  (ตัวใหม่จากแพ็กนี้) เข้าไป
   * GitHub จะขึ้นว่าไฟล์นี้ "replace" ตัวเก่า — ถูกต้อง ปล่อยผ่าน
5) กด "Commit changes"
   * manifest.json กับ the-voider.lua ที่อัปไปแล้ว ใช้ได้อยู่แล้ว
     ไม่ต้องลบ ไม่ต้องอัปใหม่ ไม่ต้องแตะอะไรทั้งสองไฟล์

อัปเดตฉบับที่ 2 (2026-10-01): แก้บั๊ก Volt แล้ว — VoltCompat v1
================================================================
อาการเดิมที่คุณเจอ (จากคอนโซล Volt):
  :1: attempt to call a nil value
      -> ตอนนั้น repo ยังไม่มี loader.lua (โหลดได้หน้าเปล่า) หรือโหลดไฟล์เก่า
  :2434: attempt to index nil with 'Run' - function preflight / boot
      -> loader.lua โหลดถึง Volt แล้ว แต่โค้ดเดิมเขียนแบบ Lua บนคอม
         (ค้นหาโมดูลผ่าน rawget(_G,...)) ซึ่งแซนด์บ็อกซ์ของ Volt มองไม่เห็น
         -> ทุกโมดูลฝังกลายเป็น nil แล้วพังที่ preflight ทันที

สิ่งที่แก้แล้ว (VoltCompat v1 — แก้ใน loader.lua เท่านั้น):
  F1  _pkg x3 จุด: อ่านโมดูลจาก chunk env ก่อน แล้วค่อย fallback ไป _G
  F2  defaultLoadFn: หา loadstring/load แบบเดียวกัน
  F3  ค่า default ของ self.env: ใช้ getfenv() (chunk env) ก่อน _G
      เพื่อให้เจอ http_request ของ Volt เสมอ
  F4  การตรวจ bit32/bit: รู้จัก bit32 มาตรฐานของ Luau บน Volt
  * ทดสอบ syntax ด้วย AST parser แล้ว: ผ่าน
  * the-voider.lua กับ manifest.json ไม่ได้แตะเลย — SHA-256 ยังตรง 100%

สิ่งที่ต้องทำ: "แทนที่ loader.lua ตัวใหม่อีกครั้ง" (วิธีเดิมเป๊ะ)
  1) แตก zip นี้  2) Add file -> Upload files  3) ลาก loader.lua (ตัวใหม่)
  4) Commit changes   5) รัน loadstring เดิม

สัญญาณที่ควรเห็นในคอนโซล (F9) หลังแก้:
  - ผ่าน preflight (ไม่มี error :2434 อีก)
  - "ดึง manifest" -> ตรวจ SHA-256 ผ่าน
  - "โหลดสำเร็จ v0.7.0 (releaseId r2026-10-01-16, channel stable)"
  - "ระบบ v0.7.0 พร้อมใช้งาน"

ถ้ายังมี error: ถ่ายภาพคอนโซล F9 ทั้งหน้าส่งมา — ข้อความผิดพลาดของ loader
เป็นภาษาไทยชัดเจน จะชี้จุดแก้ได้ทันที

อัปเดตฉบับที่ 3 (2026-10-02): VoltCompat v1b — แก้ "ไม่มี task library"
================================================================
อาการเดิม (จากคอนโซล Volt ของคุณ):
  [Loader][info] ตรวจสอบความถูกต้นฉบับ: เต็มรูปแบบ (โหมดซอฟต์แวร์, 401.7 ms)
  [Loader][error] รัน bundle v0.7.0 ไม่สำเร็จ:
  the-voider.lua:0.7.0:1293: Runtime.Spawn: ไม่มี task library (ctx.task)

ความหมาย:
  - VoltCompat v1 ได้ผลแล้ว: preflight ผ่าน, ดึงไฟล์ครบ, ตรวจ SHA-256 ผ่าน
    (โหมดซอฟต์แวร์ = คำนวณ hash ด้วย Lua ล้วน เพราะ Volt ไม่เปิด bit32 - ปกติ)
  - ตอนนี้พังขั้นถัดไป: ตัว bundle หา library "task" ของ Roblox ไม่เจอ
    เพราะค้นด้วย rawget(_G) ช่องเดียว ซึ่ง Volt มองไม่เห็น (เหตุผลเดียวกับ v1)

สิ่งที่แก้ (v1b — แก้ใน loader.lua เท่านั้น the-voider.lua/manifest ไม่แตะ):
  1) ก่อนรัน bundle จะสำรวจหาสิ่งที่ Volt ซ่อนไว้จากทุกช่องทาง
     (chunk env ผ่าน getfenv / _G / getgenv) แล้วส่งต่อเข้า _G + getgenv
     ให้ bundle มองเห็น: task, Instance, game, workspace, Drawing, warn,
     readfile, writefile, isfile, setclipboard, gethui, getgenv
  2) ถ้าไม่พบ task จริงเลย จะสร้าง "task shim" ฉุกเฉินจาก
     coroutine + RunService.Heartbeat ให้ระบบเดินต่อได้ทันที
  * ทดสอบ syntax ด้วย AST parser แล้ว: ผ่าน

สิ่งที่ต้องทำ: แทนที่ loader.lua อีกครั้ง (วิธีเดิมเป๊ะ - 1 นาที)
  แตก zip -> Add file -> Upload files -> ลาก loader.lua ตัวใหม่ -> Commit
  (manifest.json / the-voider.lua ไม่ต้องแตะ)
  แล้วรัน loadstring เดิม

สัญญาณที่ควรเห็นใน F9 หลังแก้:
  - ไม่มี "ไม่มี task library" อีก
  - "โหลดสำเร็จ v0.7.0 (releaseId r2026-10-01-16, channel stable)"
  - "ระบบ v0.7.0 พร้อมใช้งาน" = เมนูโผล่ในเกม

อัปเดตฉบับที่ 4 (2026-10-02): VoltCompat v1c — แก้ UI crash บรรทัด 7377
================================================================
อาการเดิม:
  รัน bundle v0.7.0 ไม่สำเร็จ: the-voider.lua:0.7.0:7377: attempt to index nil with 'obj'

ความหมาย + สิ่งที่แก้:
  - v1b ได้ผล: task library ใช้ได้แล้ว (ไม่มี warn ของ shim = เจอ task จริง)
  - คราวนี้พังที่ชั้น UI: ตัว backend สร้าง handle ไม่สำเร็จแล้วส่ง nil ต่อ
    แต่โค้ด UI กว่า 40 จุดชี้ .obj ทันทีโดยไม่ตรวจ nil -> boot ตายทั้งระบบ
  - แก้ 2 จุดใน the-voider.lua (แล้ว regenerate manifest.json ใหม่):
    P1 Registry: หา task/Drawing/Instance จากทุกช่องทาง (plain read + getgenv)
    P2 Backend:Create: ห้ามคืน nil อีกต่อไป - คืน "null handle" (เขียน property
       = no-op อ่าน = nil) + log เหตุผลจริงเป็นภาษาไทย -> ครอบคลุม caller
       ทั้ง 40+ จุดในครั้งเดียว boot ไม่มีทางตายจาก UI อีก
  * ทดสอบ syntax ด้วย AST parser แล้ว: ผ่านทั้ง loader และ bundle

สิ่งที่ต้องอัปโหลดรอบนี้: 2 ไฟล์ (the-voider.lua + manifest.json)
  - loader.lua ใน repo เป็นตัวล่าสุดอยู่แล้ว ไม่ต้องแตะ
